Diagramas de Flujo — Simulador de Colas

Lógica de cada evento del motor de simulación y sus modificadores.

motor.js

Loop principal — paso()

Implementa el algoritmo next-event-time. En cada tick calcula el mínimo entre tres candidatos: la próxima llegada, el próximo fin de servicio y el menor de los eventos extra de modificadores. Si ese mínimo supera el horizonte de simulación, finaliza. Si no, despacha el evento al handler correspondiente y se reprograma con setTimeout para permitir que el navegador renderice entre pasos. El fin de servicio se trata como ∞ mientras _servidorPresente === false (servidor en descanso), congelándolo hasta que el servidor regrese. 

flowchart TD
    A([paso]) --> B{corriendo?}
    B -->|No| STOP([Terminar])
    B -->|Sí| H1[hooks onPaso]
    H1 --> C1[llegada = proximoEventoLlegada]
    C1 --> C2["finSvc = _servidorPresente ? proximoFinSvc : ∞"]
    C2 --> C3[extra = min de _eventosExtra]
    C3 --> F["proximo = min(llegada, finSvc, extra)"]
    F --> G{proximo > tiempoTotal?}
    G -->|Sí| FIN["_finalizar\nhooks onFin · Bus fin"]
    G -->|No| EX{"extra ≤ llegada\ny extra ≤ finSvc?"}
    EX -->|Sí| EVT["onEvento_nombre\neg. abandono, zs, servidor_salida, llegada_B"]
    EX -->|No| LL{llegada ≤ finSvc?}
    LL -->|Sí| PL[procesarLlegada]
    LL -->|No| PFS[procesarFinServicio]
    EVT --> T["setTimeout(paso, velocidad)"]
    PL --> T
    PFS --> T
    T -.->|siguiente tick| A
motor.js

Evento LLEGADA — procesarLlegada()

Procesa la llegada de un nuevo cliente al sistema. Primero ejecuta los hooks onLlegada: el modificador de prioridades marca al cliente como Tipo A (prioridad = 1); el de seguridad puede devolver false para redirigir al cliente a la Zona de Seguridad, cancelando el flujo estándar de encolar/servir. Si ningún hook devuelve false, se aplica FCFS con prioridades. Después de encolar, el hook onLlegadaPost de abandono asigna el tiempoLimite si el cliente quedó en cola. 

flowchart TD
    A([LLEGADA]) --> B[tiempoActual = proximoEventoLlegada]
    B --> B2["clienteIdCounter++ · crear cliente"]
    B2 --> HK["hooks onLlegada\n— prioridades: tipo=A, prioridad=1\n— seguridad: puede interceptar"]
    HK --> D{algún hook\nretornó false?}
    D -->|Sí — interceptado| E[No encolar ni enviar al PS]
    D -->|No| F{servidor == LIBRE?}
    F -->|Sí| G[servidor = OCUPADO]
    G --> G2[clienteEnServicio = cliente]
    G2 --> G3["proximoFinSvc = ahora + sortear(tS)"]
    F -->|No| H[cola.push cliente]
    H --> H2[cola.sort desc por prioridad]
    E --> I
    G3 --> I
    H2 --> I
    I["proximoEventoLlegada = ahora + sortear(tLL)"] --> J["hooks onLlegadaPost\n— abandono: asigna tiempoLimite si en cola"]
    J --> K["Bus.emitir LLEGADA #id"]
    K --> Z([FIN])

Evento FIN DE SERVICIO — procesarFinServicio()

El cliente en el PS termina de ser atendido. Si _servidorPresente === false (servidor en descanso), el evento se ignora hasta que el servidor regrese. De lo contrario: se contabiliza el cliente atendido y el tiempo de espera. Si hay cola, el siguiente cliente pasa al PS. El hook onFinServicioPost de seguridad puede interceptar al siguiente cliente y enviarlo a la ZS antes del servicio; el de abandono reagenda el próximo abandono con la cola actualizada. 

flowchart TD
    A([FIN SERVICIO]) --> GP{_servidorPresente?}
    GP -->|false — congelado por descanso| RET([RETURN: ignorar])
    GP -->|true| B[tiempoActual = proximoEventoFinServicio]
    B --> B2[clienteAtendido = clienteEnServicio]
    B2 --> HK1[hooks onFinServicio]
    HK1 --> C[stats.clientesAtendidos++]
    C --> C2["tiempoEsperaTotal += inicio - llegada"]
    C2 --> D{cola.length > 0?}
    D -->|Sí| E[siguiente = cola.shift]
    E --> E2[siguiente.tiempoInicioServicio = ahora]
    E2 --> E3[clienteEnServicio = siguiente]
    E3 --> E4["proximoFinSvc = ahora + sortear(tS)"]
    D -->|No| F[servidor = LIBRE]
    F --> F2[clienteEnServicio = null]
    F2 --> F3[proximoFinSvc = null]
    E4 --> HK2
    F3 --> HK2
    HK2["hooks onFinServicioPost\n— abandono: reagenda próximo abandono\n— seguridad: envía siguiente a ZS si aplica"] --> K["Bus.emitir FIN SERVICIO #id"]
    K --> Z([FIN])
modificadores/abandono.js

Evento ABANDONO — onEvento_abandono

Se dispara cuando el tiempo de simulación alcanza el mínimo tiempoLimite de los clientes en cola. Elimina todos los clientes cuyo tiempoLimite ≤ ahora (pueden ser varios simultáneos) y reagenda el evento con el próximo límite de los restantes. El tiempoLimite de cada cliente se asigna en el hook onLlegadaPost sumando la paciencia sorteada (SC) a su tiempoLlegada.

Evento principal: onEvento_abandono
flowchart TD
    A([ABANDONO]) --> B[tiempoActual = _eventosExtra.abandono]
    B --> B2[_eventosExtra.abandono = null]
    B2 --> C["buscar en cola: clientes con tiempoLimite ≤ ahora"]
    C --> D{hay clientes\nque abandonan?}
    D -->|No| G
    D -->|Sí| E["para cada cliente abandonante:\n· cola.filter → eliminar\n· stats.clientesAbandonaron++\n· Bus.emitir ABANDONO #id"]
    E --> G
    G["agendarProximoAbandono\n_eventosExtra.abandono = min tiempoLimite restante"] --> Z([FIN])
Hook onLlegadaPost: asignar tiempoLimite al cliente
flowchart TD
    A([onLlegadaPost — abandono]) --> B{cliente está\nen la cola?}
    B -->|No — fue al PS| Z([FIN: sin límite])
    B -->|Sí| C["paciencia = sortear(SC, randomParams.abandono)"]
    C --> D["cliente.tiempoLimite = tiempoLlegada + paciencia"]
    D --> E[agendarProximoAbandono: actualizar _eventosExtra.abandono]
    E --> Z2([FIN])
modificadores/seguridad.js

Evento ZONA DE SEGURIDAD — onEvento_zs

El cliente termina de cruzar la ZS y entra al PS para recibir el servicio. La interceptación ocurre en el hook onLlegada: si la ZS está libre y el PS está libre, el cliente se desvía a la ZS (retornando false para cancelar el flujo normal). Si la ZS está ocupada y el PS libre, el PS se marca como OCUPADO para que el cliente recién llegado vaya a la cola, reservando el PS para quien está cruzando. El hook onFinServicioPost encadena el siguiente cruce cuando termina un servicio.

Evento principal: onEvento_zs (fin de cruce)
flowchart TD
    A([EVENTO ZS]) --> B[tiempoActual = _eventosExtra.zs]
    B --> B2[_eventosExtra.zs = null]
    B2 --> C[cliente = clienteEnZona]
    C --> C2[zonaSeguridad = LIBRE · clienteEnZona = null]
    C2 --> D[cliente.tiempoInicioServicio = ahora]
    D --> D2[clienteEnServicio = cliente · servidor = OCUPADO]
    D2 --> D3["proximoFinSvc = ahora + sortear(tS)"]
    D3 --> E["Bus.emitir LLEGA AL PS #id"]
    E --> Z([FIN])
Hook onLlegada: interceptar cliente hacia la ZS
flowchart TD
    A([onLlegada — seguridad]) --> B{"zonaSeguridad == LIBRE\ny servidor == LIBRE?"}
    B -->|Sí| C[zonaSeguridad = OCUPADO · clienteEnZona = cliente]
    C --> C2["_eventosExtra.zs = ahora + sortear(tCruce)"]
    C2 --> C3[return false — cancelar flujo normal]
    C3 --> ZA([FIN: interceptado])
    B -->|No| D{"zonaSeguridad == OCUPADO\ny servidor == LIBRE?"}
    D -->|Sí| E[servidor = OCUPADO reservar PS]
    E --> ZB([FIN: continúa procesarLlegada])
    D -->|No — servidor ocupado| ZB
Hook onFinServicioPost: encadenar siguiente cruce
flowchart TD
    A([onFinServicioPost — seguridad]) --> B{hay nuevo cliente\nen PS tras pop de cola?}
    B -->|No — cola estaba vacía| Z([FIN: sin acción])
    B -->|Sí| C[sacar cliente del PS temporalmente]
    C --> C2[proximoFinSvc = null · servidor = LIBRE · clienteEnServicio = null]
    C2 --> D[zonaSeguridad = OCUPADO · clienteEnZona = cliente]
    D --> D2["_eventosExtra.zs = ahora + sortear(tCruce)"]
    D2 --> Z2([FIN: cliente va a cruzar ZS])
modificadores/descanso.js

Evento SALIDA SERVIDOR — onEvento_servidor_salida

El servidor inicia su período de descanso de duración ΔD. Se activan los flags _servidorPresente = false y _servidorAusente = true, lo que hace que el bucle principal ignore el fin de servicio mientras el servidor está ausente. Si hay un cliente siendo atendido, su tiempo de servicio restante se guarda en _tiempoRestante y el cliente permanece en el PS congelado. 

flowchart TD
    A([SALIDA SERVIDOR]) --> B[tiempoActual = _eventosExtra.servidor_salida]
    B --> B2[_eventosExtra.servidor_salida = null]
    B2 --> C[_servidorPresente = false · _servidorAusente = true]
    C --> D["sortear ΔD\n_eventosExtra.servidor_llegada = ahora + ΔD"]
    D --> E{clienteEnServicio\n!= null?}
    E -->|Sí — hay cliente en PS| F["_tiempoRestante = proximoFinSvc - ahora\n(PS queda congelado)"]
    E -->|No — PS vacío| G[sin acción extra]
    F --> H["Bus.emitir SALIDA SERVIDOR"]
    G --> H
    H --> Z([FIN])
modificadores/descanso.js

Evento LLEGADA SERVIDOR — onEvento_servidor_llegada

El servidor regresa del descanso. Se restauran los flags de presencia y se agenda el próximo ciclo de trabajo (ΔT). Si había un cliente congelado en el PS, su servicio se reanuda con el tiempo restante guardado. Si no hay cliente en PS pero hay cola, se atiende al siguiente. Si no hay nadie, el PS queda libre. 

flowchart TD
    A([LLEGADA SERVIDOR]) --> B[tiempoActual = _eventosExtra.servidor_llegada]
    B --> B2[_eventosExtra.servidor_llegada = null]
    B2 --> C[_servidorPresente = true · _servidorAusente = false]
    C --> D["sortear ΔT\n_eventosExtra.servidor_salida = ahora + ΔT"]
    D --> E{clienteEnServicio\n!= null?}
    E -->|Sí — cliente congelado| F[reanudar servicio]
    F --> F2[proximoFinSvc = ahora + _tiempoRestante]
    F2 --> F3[cliente.tiempoInicioServicio = ahora · servidor = OCUPADO]
    E -->|No| G{cola.length > 0?}
    G -->|Sí| H[siguiente = cola.shift]
    H --> H2[siguiente.tiempoInicioServicio = ahora · servidor = OCUPADO]
    H2 --> H3["proximoFinSvc = ahora + sortear(tS)"]
    G -->|No| I[servidor = LIBRE]
    F3 --> J["Bus.emitir LLEGADA SERVIDOR"]
    H3 --> J
    I --> J
    J --> Z([FIN])
modificadores/prioridades.js

Evento LLEGADA B — onEvento_llegada_B

Canal independiente de llegadas para clientes Tipo B (prioridad = 0). Replica la lógica de procesarLlegada() sin pasar por los hooks de llegada (no necesita interacción con otros modificadores). Al ordenar la cola por prioridad descendente, los Tipo A (prioridad = 1) siempre quedan delante de los B. El próximo evento llegada_B se reagenda con el intervalo tLL_B configurado. 

flowchart TD
    A([LLEGADA B]) --> B[tiempoActual = _eventosExtra.llegada_B]
    B --> B2["clienteIdCounter++ · crear cliente B {prioridad: 0}"]
    B2 --> D{servidor == LIBRE?}
    D -->|Sí| E[servidor = OCUPADO]
    E --> E2[clienteEnServicio = cliente]
    E2 --> E3[proximoFinSvc = ahora + tS]
    D -->|No| F[cola.push cliente B]
    F --> F2[cola.sort desc prioridad]
    F2 --> F3[A quedan delante de B]
    E3 --> G
    F3 --> G
    G["_eventosExtra.llegada_B = ahora + tLL_B"] --> H["Bus.emitir LLEGADA B #id"]
    H --> Z([FIN])
